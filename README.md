# An Xin Portfolio / 安馨个人作品集

An English-first bilingual portfolio for interaction design, cultural technology, digital products and HCI research.

## Local development

```bash
pnpm install
pnpm dev
```

## Production check

```bash
pnpm build
```

## Content system

- The interface is English-first.
- Project names and descriptions are bilingual: Chinese first, corresponding English below.
- Every project detail opens with a 16:9 introduction-film placeholder.
- Programmatic image placeholders are used until reviewed public assets are added under `assets/`.
- Placeholder media is intentionally labelled so it cannot be mistaken for final project evidence.

## Publishing

The intended public address is `https://xinan-annie.github.io/`. Publication is not performed automatically during local development.
